# 🔹 ЛАБОРАТОРНАЯ РАБОТА №4  
## Комплексная диагностика и информирование с помощью PC Wizard

### 🎯 Цель работы
Проводить диагностику компьютера с помощью программ-диагностик, получать подробную информацию о конфигурации оборудования и программного обеспечения, оценивать производительность отдельных компонентов.

### 📚 Теоретическая часть

#### Программы для диагностики компьютера
Программы для диагностики компьютера позволяют:
*   Проверить **конфигурацию компьютера**: количество и тип оперативной памяти, ее использование, типы и параметры дисков, модель процессора, версию BIOS и т.д.
*   Проверить **работоспособность устройств**: прежде всего жестких дисков, но также оперативной памяти, процессора, видеоподсистемы
*   Выявить **«намечающиеся» дефекты дисков**, возникающие из-за износа магнитной поверхности (для HDD) или износа ячеек NAND (для SSD), и предотвратить потерю данных
*   Сформировать подробный отчет о системе для целей инвентаризации, технической поддержки или апгрейда

### Вопрос 2: Для чего необходимо знать температуру процессора и жесткого диска?

Контроль температуры критически важен для:

#### 🔹 Процессор (CPU):
| Причина | Последствия игнорирования |
|---------|--------------------------|
| **Предотвращение троттлинга** | При достижении критической температуры (~95-100°C) процессор автоматически снижает частоту, что приводит к падению производительности |
| **Продление срока службы** | Постоянная работа при высоких температурах ускоряет деградацию кристалла и термоинтерфейса |
| **Стабильность системы** | Перегрев может вызывать случайные перезагрузки, синие экраны (BSOD), ошибки в вычислениях |
| **Энергоэффективность** | Оптимальная температура позволяет системе работать в штатных режимах энергосбережения |

#### 🔹 Жесткий диск (HDD/SSD):
| Причина | Последствия игнорирования |
|---------|--------------------------|
| **Надежность хранения данных** | Для HDD: перегрев вызывает тепловое расширение компонентов, увеличивая риск механических повреждений. Для SSD: высокая температура ускоряет деградацию ячеек NAND |
| **Производительность** | Некоторые накопители снижают скорость при перегреве для защиты |
| **Раннее предупреждение сбоев** | Рост температуры может сигнализировать о неисправности системы охлаждения или начале отказа компонента |
| **Планирование замены** | Мониторинг помогает вовремя заменить диск до потери данных |

> 📌 **Рекомендуемые температурные диапазоны:**  
> • CPU: 30-60°C (простой), до 80°C (нагрузка)  
> • HDD: 30-45°C  
> • SSD: 30-50°C  
> • Системная плата: 30-45°C

### Вопрос 3: Какие данные о жестком диске можно получить в программе и почему они важны?

PC Wizard предоставляет следующие ключевые данные о жестком диске:

| Данные | Почему это важно |
|--------|----------------|
| **Модель и производитель** | Позволяет найти спецификации, драйверы, информацию о известных проблемах модели |
| **Емкость и геометрия** | Необходима для планирования размещения данных, создания разделов, резервного копирования |
| **Интерфейс (SATA/NVMe/IDE)** | Определяет максимальную пропускную способность и совместимость с материнской платой |
| **Режим передачи (UDMA Mode)** | Показывает, работает ли диск на максимальной скорости интерфейса |
| **Температура** | Критический параметр для оценки надежности и профилактики сбоев |
| **Время наработки (Power-On Hours)** | Позволяет оценить износ диска и спланировать своевременную замену |
| **Параметры S.M.A.R.T.** | Система самодиагностики, предупреждающая о возможных отказах (реallocated sectors, pending sectors, temperature и др.) |
| **Структура разделов** | Информация о разметке диска необходима для администрирования, восстановления данных, установки ОС |
| **Серийный номер** | Нужен для гарантийного обслуживания, инвентаризации, идентификации устройства |

> 💡 **Особенно важны атрибуты S.M.A.R.T.**:  
> • `Reallocated_Sector_Ct` — количество переназначенных секторов (рост = износ поверхности)  
> • `Current_Pending_Sector` — секторы, ожидающие переназначения (предвестник сбоя)  
> • `Uncorrectable_Error_Count` — неисправимые ошибки чтения/записи  
> • `Temperature_Celsius` — текущая температура  
> • `Power_On_Hours` — общее время работы

### Вопрос 4: Чем отличается вкладка "Аппаратное обеспечение" от вкладки "Конфигурация"?

| Критерий | **Аппаратное обеспечение** 🔧 | **Конфигурация** ⚙️ |
|----------|------------------------------|-------------------|
| **Основное назначение** | Информация о физических компонентах ПК («железо») | Информация о программной среде и настройках системы |
| **Примеры данных** | • Модель CPU, частота, кэш<br>• Объем и тип RAM<br>• Модель HDD/SSD, интерфейс<br>• Видеокарта, GPU, видеопамять<br>• Материнская плата, чипсет, BIOS<br>• Сенсоры: температура, напряжение | • Версия ОС, сборка, пакет обновлений<br>• Установленные драйверы и их версии<br>• Активные процессы и службы<br>• Переменные среды, системные пути<br>• Установленные библиотеки (.NET, DirectX)<br>• Политики безопасности, настройки реестра |
| **Когда используется** | • При диагностике аппаратных сбоев<br>• При подборе компонентов для апгрейда<br>• При проверке совместимости оборудования<br>• Для инвентаризации «железа» | • При устранении программных конфликтов<br>• При настройке системы под конкретные задачи<br>• При анализе причин сбоев ПО<br>• Для подготовки отчетов о программной среде |
| **Динамичность данных** | Относительно статична (меняется только при замене компонентов) | Высокодинамична (процессы, службы, настройки меняются постоянно) |
| **Связь с драйверами** | Показывает, какое оборудование установлено | Показывает, какие драйверы для этого оборудования загружены и активны |

> ✅ **Вывод:** Вкладки дополняют друг друга: «Аппаратное обеспечение» отвечает на вопрос **«Что установлено?»**, а «Конфигурация» — **«Как это работает и настроено?»**.

### Вопрос 5: Какую информацию о программном обеспечении предоставляет PC Wizard?

PC Wizard предоставляет исчерпывающую информацию о программной среде:

*   Разрядность (32/64-bit)

#### 🔹 Сеть и безопасность:
*   IP-конфигурация адаптеров (IP, маска, шлюз, DNS)
*   Открытые порты и активные сетевые подключения
*   Настройки брандмауэра и антивирусной защиты

#### 🔹 Дополнительно:
*   Установленные шрифты и кодеки
*   Настройки электропитания и управления энергопотреблением

### Вопрос 6: Для чего используются тесты производительности (бенчмарки)?

Бенчмарки выполняют несколько критически важных функций:

#### 🔹 Сравнительный анализ:
| Задача | Как помогают бенчмарки |
|--------|----------------------|
| **Оценка апгрейда** | Позволяют количественно измерить прирост производительности после замены компонента (например, «после установки SSD скорость диска выросла в 5 раз») |
| **Выбор оборудования** | Сравнение результатов разных моделей процессоров/видеокарт помогает принять обоснованное решение о покупке |
| **Балансировка системы** | Выявление «узких мест»: если CPU показывает высокий результат, а диск — низкий, значит, именно диск ограничивает общую производительность |

#### 🔹 Диагностика и мониторинг:
| Задача | Как помогают бенчмарки |
|--------|----------------------|
| **Выявление деградации** | Регулярное тестирование позволяет заметить падение производительности, которое может сигнализировать о неисправности (например, износ SSD, перегрев CPU) |
| **Проверка стабильности** | Стресс-тесты под нагрузкой выявляют нестабильность, вызванную разгоном, плохим охлаждением или дефектами компонентов |
| **Верификация настроек** | После изменения настроек BIOS (включение XMP, изменение таймингов) бенчмарки подтверждают, что изменения дали ожидаемый эффект |

#### 🔹 Профессиональные сценарии:
| Сфера применения | Пример использования |
|-----------------|---------------------|
| **Системная интеграция** | Формирование отчетов для заказчика с объективными показателями производительности собранной системы |
| **Техническая поддержка** | Воспроизведение проблемы: если на эталонной системе бенчмарк проходит, а на проблемной — нет, это сужает круг поиска причин |
| **Разработка ПО** | Тестирование производительности приложения на разных конфигурациях для оптимизации кода |
| **Образование** | Наглядная демонстрация влияния архитектурных решений на производительность (кэш-память, многопоточность, SSD vs HDD) |

#### 🔹 Типы бенчмарков в PC Wizard:
```
✓ CPU Benchmark — однопоточная и многопоточная производительность процессора
✓ RAM Benchmark — пропускная способность и задержки оперативной памяти  
✓ Disk Benchmark — скорость последовательного и случайного доступа к накопителю
✓ Video Benchmark — производительность 2D/3D-подсистемы
✓ Global Memory Test — комплексная оценка взаимодействия CPU+RAM+чипсет
```

> 📌 **Важно:** Для корректного сравнения результатов необходимо:  
> • Запускать тесты при одинаковых условиях (фоновые процессы отключены, температура в норме)  
> • Использовать одну и ту же версию программы и настройки теста  
> • Проводить несколько запусков и усреднять результаты
