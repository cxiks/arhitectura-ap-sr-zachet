

# 🔹 ЛАБОРАТОРНАЯ РАБОТА №3  
## Диагностика работоспособности ПК с помощью PassMark BurnInTest

### 🎯 Цель работы
Провести диагностику компьютера с помощью программ-диагностик, проверить стабильность и надежность системы под нагрузкой, выявить потенциальные аппаратные неисправности.

### 📚 Теоретическая часть

#### Программы для диагностики компьютера
Программы для диагностики компьютера позволяют:
*   Проверить конфигурацию компьютера (количество памяти, ее использование, типы дисков, версии драйверов и т.д.)
*   Проверить работоспособность устройств компьютера (прежде всего жестких дисков, оперативной памяти, процессора, видеоподсистемы)
*   Выявить «намечающиеся» дефекты дисков (возникающие из-за износа магнитной поверхности диска или износа ячеек NAND в SSD) и предотвратить потерю данных, хранящихся на диске
*   Провести стресс-тестирование для проверки стабильности системы при пиковых нагрузках

#### Возможности диагностических комплексов
С помощью тестового программного продукта или диагностического комплекса можно определить ряд несложных неисправностей аппаратуры или неправильного конфигурирования системных файлов. Диагностика может выполняться:

🔹 **Для системы в целом:**
*   Комплексное тестирование всех подсистем одновременно
*   Оценка общей стабильности и производительности

🔹 **Для отдельных модулей:**
| Модуль | Что проверяется |
|--------|----------------|
| **Системная плата** | Стабильность питания, температура чипсета, работа шин данных |
| **Память (RAM)** | Тестирование стандартной, дополнительной и расширенной памяти на ошибки чтения/записи |
| **Видеоподсистема** | Работа 2D/3D-ускорителей, стабильность видеодрайвера, температура GPU |
| **Жесткие диски** | Скорость чтения/записи, время доступа, поиск bad-секторов, анализ S.M.A.R.T. |
| **Приводы флоппи-дисков** | *(устаревший компонент, проверяется на совместимость)* |
| **Клавиатура** | Регистрация всех нажатий клавиш, отсутствие «залипаний» |
| **Порты (COM/LPT/USB)** | Корректность передачи данных, скорость работы, стабильность подключения |
| **Координатные устройства** | Точность позиционирования мыши, отклик тачпада |
| **Приводы CD/DVD/Blu-ray** | Скорость чтения, качество чтения поврежденных дисков |
| **SCSI-устройства** | Работа специализированных накопителей и контроллеров |

### 💻 Программа PassMark BurnInTest

**BurnInTest** — профессиональная программа для испытания компьютера «на прочность». 

#### 🔹 Основные возможности:
*   Тестирует стабильность и надёжность ПК под длительной нагрузкой
*   Синхронно распределяет нагрузку на все подсистемы для выявления «узких мест»
*   Позволяет осуществлять проверку:
    *   Скорости и стабильности процессора (CPU)
    *   Оперативной памяти (RAM) на ошибки
    *   Жестких дисков и SSD (чтение/запись, время отклика)
    *   CD/DVD/Blu-ray приводов
    *   Звуковых карт (запись и воспроизведение)
    *   Видеокарт (2D и 3D-рендеринг)
    *   Принтеров и сканеров
    *   Сетевых устройств (пропускная способность, стабильность соединения)

#### 🔹 Преимущества программы:
✅ Поддержка многопоточного тестирования  
✅ Гибкая настройка длительности и интенсивности тестов  
✅ Подробное логирование результатов и ошибок  
✅ Возможность создания отчетов в различных форматах  
✅ Поддержка скриптов для автоматизации тестирования
