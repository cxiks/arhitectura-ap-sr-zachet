

## 📂 1. Навигация по файловой системе

| Команда | Описание |
| :--- | :--- |
| `pwd` | Показать текущий путь (**P**rint **W**orking **D**irectory) |
| `ls` | Список файлов в текущей папке |
| `ls -la` | Подробный список всех файлов (включая скрытые) |
| `cd ~` | Перейти в домашнюю директорию |
| `cd ..` | Подняться на уровень выше |
| `cd -` | Вернуться в предыдущую директорию |
| `cd /path/to/folder` | Перейти по абсолютному пути |
| `cd "Folder Name"` | Перейти в папку с пробелами (в кавычках) |

## 📁 2. Управление файлами и папками

### Создание
```bash
touch file.txt          # Создать пустой файл
mkdir new_folder        # Создать папку
mkdir -p a/b/c          # Создать вложенную структуру папок
```

### Копирование и Перемещение
```bash
cp source.txt dest/     # Копировать файл
cp -r folder/ dest/     # Копировать папку рекурсивно
mv old.txt new.txt      # Переименовать файл
mv file.txt ../         # Переместить файл на уровень выше
```


```bash
rm file.txt             # Удалить файл
rmdir empty_folder      # Удалить пустую папку
rm -r folder/           # Удалить папку с содержимым
rm -rf folder/          # Принудительное удаление без вопросов (Опасно!)
```

## 📄 3. Чтение и анализ файлов

| Команда | Назначение |
| :--- | :--- |
| `cat file.txt` | Вывести всё содержимое файла |
| `less file.txt` | Постраничный просмотр (выход: `q`) |
| `head -n 10 file` | Первые 10 строк |
| `tail -n 10 file` | Последние 10 строк |
| `tail -f log.txt` | Следить за обновлением файла в реальном времени (логи) |
| `wc -l file.txt` | Посчитать количество строк |

## 🔍 4. Поиск

### Поиск текста внутри файлов (`grep`)
```bash
grep "error" log.txt            # Найти строки с "error"
grep -i "text" file.txt         # Искать без учета регистра
grep -r "TODO" ./src/           # Рекурсивный поиск в папке
```

### Поиск файлов (`find`)
```bash
find . -name "*.jpg"            # Найти все jpg файлы
find . -type f -size +100M      # Найти файлы больше 100 МБ
which python                    # Где лежит исполняемый файл python
```

## 🔐 5. Права доступа

Просмотр прав: `ls -l`

| Команда | Действие |
| :--- | :--- |
| `chmod +x script.sh` | Сделать файл исполняемым |
| `chmod 755 file` | Владелец: полный доступ, Остальные: чтение+исполнение |
| `chown user:group file` | Сменить владельца и группу |
| `sudo chown root file` | Сменить владельца на root (требует прав суперпользователя) |

## ⚙️ 8. Процессы и Система

### Мониторинг
*   `top` или `htop` — Диспетчер задач в реальном времени.
*   `df -h` — Свободное место на дисках.
*   `du -sh folder/` — Размер конкретной папки.
*   `free -h` — Использование оперативной памяти.

### Управление процессами
```bash
ps aux                  # Список всех процессов
kill 1234               # Завершить процесс по PID
kill -9 1234            # Принудительно убить процесс
pkill firefox           # Завершить процесс по имени
```
